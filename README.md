# OD's Honeysuckle & Mint Products Website

This is a deployable React/Vite shop website.

## Features

- Real product list from the app
- Categories: All, Honeysuckle, Mint, Add Ons
- Product search and sorting
- Best-seller, low-stock, and sold-out badges
- Cart with quantity controls
- Pickup or delivery checkout
- Delivery fee and order total
- Demo customer account section
- Business hours
- Order history saved in the browser with localStorage
- Responsive layout for phone, tablet, and desktop

## Run locally

```bash
npm install
npm run dev
```

## Build for publishing

```bash
npm run build
```

## Free hosting options

You can upload this project to GitHub and deploy it with Vercel or Netlify free hosting.

A custom .com domain usually costs money. The hosting can be free, but the .com domain normally needs to be purchased from a registrar, then connected to the free hosting site.
